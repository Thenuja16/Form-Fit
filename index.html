01 / ABOUT THE PROJECT

What is FORM FIT?

FORM FIT is an embedded systems and machine learning project that helps users understand their bicep curl technique. It uses motion sensors and a trained machine learning model to recognise movement patterns and provide feedback.

⌚

Wearable Device

A compact wrist-worn device designed for workout monitoring.

🧠

Machine Learning

Recognises correct and incorrect movement patterns using a trained model.

📳

Instant Feedback

Uses vibration and an OLED display to communicate detected mistakes.

02 / FEATURES

Smart Training Features

01. Motion Detection

Measures wrist and arm movement using an IMU motion sensor.

02. AI Classification

Uses an Edge Impulse machine learning model to classify movements.

03. Vibration Alerts

Vibrates when an incorrect movement pattern is detected.

04. OLED Display

Displays feedback and workout information.

05. Repetition Tracking

Designed to monitor workout repetitions.

06. Portable Design

Designed to be lightweight and wearable during workouts.

04 / TECHNIQUE GUIDE

Common Bicep Curl Mistakes

Body Swinging

Avoid using body momentum to lift the weight.

Wrist Bending

Keep your wrist in a comfortable neutral position.

Moving Too Fast

Perform controlled and steady repetitions.

Elbow Movement

Keep your upper arm reasonably stable.

05 / ENGINEERING

Technology Behind FORM FIT

ESP32-S3

The main microcontroller responsible for processing sensor data and controlling outputs.

MPU6500 / MPU9250

Motion sensing using accelerometer and gyroscope measurements.

OLED Display

Displays detected movement feedback and messages.

Vibration Motor

Provides physical feedback when an incorrect movement is detected.

Edge Impulse

Machine learning platform used to develop the movement classification model.

Rechargeable Battery

Provides portable power to the wearable system.

06 / WORKING PRINCIPLE

How Does It Work?

01. Sensor Input

The IMU captures movement data.

02. Data Processing

The ESP32-S3 processes the sensor readings.

03. Machine Learning

The trained model classifies the movement.

04. Feedback

The OLED display and vibration motor communicate the result.
